# thermostat_home1 agent notes

## Что это за проект

Это небольшой проект термостата на Berry для Tasmota/HASPmota.
Основной сценарий: устройство загружает `autoexec.be`, который подключает остальные `.be`-скрипты.

## Структура файлов

- `autoexec.be` — точка входа, загружает остальные модули.
- `cmd.be` — первичная настройка Tasmota-командами, в том числе подписи веб-кнопок и offsets датчика.
- `termostat.be` — включает и настраивает встроенный thermostat mode в Tasmota.
- `tempset.be` — веб-интерфейс со слайдером для задания целевой температуры.
- `telegram.be` — Telegram-команды и уведомления по датчику/состоянию нагрева.
- `work.be` — обработчики событий `Power2#State`, `Button1#state`, логика track-режима и сохранение состояния.
- `README.md` — команды установки файлов из GitHub через `UrlFetch`.

## Важные замечания по логике

- Погода из проекта удалена. Не возвращать `weather.be` и вызовы `get_weather()`, если пользователь явно не попросит.
- В проекте уже добавлена защита от `nil` для `target_temp` и таймингов нагрева/остывания.
- Состояние `persist` должно сохраняться после переключения track-режима, кнопки и событий нагрева.

## Что учитывать при изменениях

- Пользователь не просил убирать Telegram token из кода. Не трогать token без явной команды.
- Если появляются проблемы с русским текстом, учитывать, что файлы уже пересохранялись в `UTF-8 with BOM` для совместимости с Windows/Tasmota-инструментами.
- Если меняется список файлов для развертывания, нужно обновлять `README.md`.

## Развертывание

В `README.md` уже записаны актуальные команды `Backlog UrlFetch ...` только для файлов, которые реально есть в репозитории.
Сейчас установка разбита на 3 команды.
